Proposed ESP32 Circuit Reference & Voltage Divider Topology

ESP32 GPIO = 3.3V Logic Max
Component Pin ESP32 / Circuit Target Status
Why the 1kΩ + 2kΩ Voltage Divider is Required:

The HC-SR04 powered at 5V drives its ECHO pin to 5.0V HIGH. ESP32 pins (GPIO 18) use 3.3V logic and are not 5V-tolerant.

V_GPIO18 = 5.0V × 2kΩ / (1kΩ + 2kΩ) = 3.33V ✓

Buzzer Current Note: Active buzzers can draw 25–40mA. Using the 3-pin transistor-buffered module on GPIO 23 keeps GPIO current <2mA.
